# Практична робота №1

## Моделювання випадкових подій засобами програмування

У роботі реалізовано моделювання випадкових подій засобами Python, перевірку закону великих чисел, геометричну ймовірність, оцінювання числа pi методом Монте-Карло та розв'язання прикладної задачі для API-запитів.

## Реалізовані блоки

1. **Блок 1 — Закон великих чисел.** Моделювання випробувань Бернуллі для різної кількості випробувань N, обчислення статистичної частоти та абсолютної похибки, побудова графіка збіжності.

2. **Блок 2 — Геометрична ймовірність, варіант 3.** Моделювання випадкових точок в одиничному квадраті та оцінка ймовірностей подій A, B, A∩B, A∪B і Ā.

3. **Блок 3 — Метод Монте-Карло.** Оцінювання числа pi за допомогою випадкових точок у квадраті [-1, 1] × [-1, 1] та побудова графіка збіжності до math.pi.

4. **Блок 4 — Професійна комплексна задача, варіант 3.** Обчислення статистичних ймовірностей класів відповідей 2xx, 4xx і 5xx для API-запитів.

## Запуск програми

Для запуску проєкту необхідно мати встановлений Python.

Встановити бібліотеку matplotlib:

```bash
python -m pip install matplotlib
```

Запуск блоків 1, 3 і 4:
```bash
python src/main.py
```

Запуск блоку 2:
```bash
python src/block2_variants.py
```
